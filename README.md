# Кері байланыс әлемі

**Three.js + Node.js + Express + Socket.IO** негізіндегі көпқолданушылы 3D рефлексия сыныбы. Ақылы AI API қолданылмайды. Three.js `npm` арқылы орнатылады және серверден жергілікті таратылады; дайын жобаға бөлек CDN қажет емес.

## Негізгі мүмкіндіктер

- Мұғалім 1–3 сұрақпен бөлме ашады, сілтеме/код/QR алады; токен мұғалім әрекеттері мен CSV жүктеуді қорғайды.
- Оқушы лақап атпен кіріп, киім түсі мен шаш/бас киімді таңдайды; 3D аватарлар, аяқ-қол қозғалысы, есім белгілері.
- Бір бөлмеге 30 оқушыға дейін; Socket.IO арқылы қозғалыс, online күйі, қорытындылар таратылады. Бөлмелер оқшауланған.
- Жасыл, сары, қызыл аймаққа **жақындау + батырмамен растау + 1–3 жазбаша жауап**; жай өтудің өзі жауап емес.
- Мұғалім тек өз панелінен жазбаша жауаптарды оқиды, CSV жүктейді және бөлмені басқарады. Оқушыларға тек сандық статистика мен аватарлар беріледі.
- Бір оқушының қайталама жауабы алдыңғысын алмастырады; браузердегі оқушы құпия токені арқылы қайта кіреді. Сервер `data/rooms.json` файлына жауап пен аватар күйін сақтайды.
- Серверде мәтін ұзындығы, жиілік шектеуі, токен, қозғалыс жылдамдығы/шекара/жиһаз және аймаққа жақындық тексеріледі; мәтін DOM-ға `textContent` арқылы орналастырылады.

## Windows (PowerShell)

1. [Node.js](https://nodejs.org/) 20 немесе 22 LTS орнатыңыз.
2. ZIP-ті шығарыңыз, жоба қалтасына кіріңіз:
   ```powershell
   cd C:\Users\YOUR_NAME\Downloads\keri-bailanys-alemi
   npm install
   npm start
   ```
3. Мұғалім браузерінен `http://localhost:3000` ашыңыз.
4. LAN IPv4 мекенжайды табыңыз: `ipconfig` → Wi-Fi → **IPv4 Address** (мысалы, `192.168.1.20`). Оқушыларға **`http://192.168.1.20:3000`** беріңіз. `localhost` телефонда **жұмыс істемейді**.
5. Windows Defender Firewall сұраса, **Private networks** үшін Node.js-ке рұқсат беріңіз. Қажет болса Windows Defender Firewall → Advanced settings → Inbound Rules → New Rule → TCP port 3000 → Private (тек сенімді Wi-Fi). Public желілерде ашпаңыз.

## macOS (Terminal)

```bash
cd ~/Downloads/keri-bailanys-alemi
npm install
npm start
```

Mac-та `http://localhost:3000` ашылады. Жергілікті Wi-Fi IP табу:

```bash
ipconfig getifaddr en0
```

Егер Wi-Fi `en0` емес болса, **System Settings → Wi-Fi → Details → TCP/IP** ішіндегі IPv4 Address қараңыз. Телефонға `http://MAC_IP:3000` беріңіз. **System Settings → Network → Firewall → Options** ішінен Node.js кіріс байланысына рұқсат беріңіз; үшінші тарап брандмауэрі болса TCP 3000 рұқсат етіңіз.

**Маңызды:** Мұғалім мен оқушылар бір Wi-Fi-да, бір-біріне қатынайтын желіде болуы керек. «Guest Wi-Fi», AP/client isolation немесе VPN байланысқа кедергі келтіруі мүмкін. Бөлмені **LAN IP арқылы ашыңыз**, сонда берілетін QR/сілтеме де LAN IP-мен жасалады. Егер мұғалім localhost-пен бөлме ашса, QR-де localhost болуы мүмкін: телефонға берілетін сілтемені LAN IP-мен ауыстырыңыз немесе `PUBLIC_URL=http://LAN_IP:3000` орнатыңыз.

## Интернетте іске қосу — Render

1. Жоба файлдарын жеке GitHub репозиторийге жүктеңіз (құпия деректер сақталатын `data/` қалтасын **жүктемеңіз**).
2. [render.com](https://render.com/) → **New → Web Service** → GitHub репозиторийді таңдаңыз.
3. Environment: **Node**; Build Command: `npm install`; Start Command: `npm start`.
4. Render `PORT` айнымалысын береді, сервер `0.0.0.0` адресін тыңдайды. Орналастырғаннан кейін HTTPS URL шығады: `https://YOUR-SERVICE.onrender.com`.
5. **Environment Variables**: `PUBLIC_URL=https://YOUR-SERVICE.onrender.com`.
6. Тұрақты сақтау үшін **persistent disk** қолдайтын тариф/хостинг қолданыңыз және `DATA_FILE=/var/data/rooms.json` деп орнатыңыз. Render-де disk тіркелсе `/var/data` каталогына бекітіңіз. Дисксіз хостингтің қайта орналастыруы/рестарты бөлмелер мен жауаптарды жоя алады.
7. Socket.IO үшін WebSocket қолдайтын сервис пайдаланыңыз, **бір instance** күйінде қалдырыңыз (көлденең масштабтау үшін Socket.IO adapter + ортақ DB қажет). Кейбір тегін хостингтер бос тұрса ұйықтайды.

**Қауіпсіздік:** интернетте тарату үшін HTTPS пен сенімді аккаунт/қолжетімділік саясатын ойластырыңыз. Мұғалім токені ағымдағы браузердің `sessionStorage` ішінде сақталады, URL-ға қойылмайды. Токенді жарияламаңыз. Оқушы токені `localStorage` ішінде қалады. Бір браузер профилін ортақ қолданбаңыз.

## Қолдану

1. Мұғалім «Мұғалім бөлмесін ашу» → тақырып, сұрақтар → «Бөлме ашу».
2. Оқушы «Оқушы ретінде кіру», код пен лақап ат, аватар таңдау → «3D сыныпқа кіру».
3. Мұғалім «Бастау». Компьютерде WASD/көрсеткілермен, телефонда джойстикпен қозғалу. Камераны экранды сүйреумен бұру.
4. Түсті аймаққа жақындау → «Жауап беру» → мәтін жазу → «Жауапты жіберу».
5. Мұғалімнің панелінде нақты нәтижелер мен мәтіндер; CSV жүктеуге болады.

## Тексеру

```bash
npm test
```

`test/integration.test.js` екі Socket.IO оқушысын іске қосуға, қозғалысты, бөлмені ашу/жабуды, жауапты жаңартуды, қайта кіруді, CSV және токенмен қорғауды тексеруге арналған.

**Шектеулер:** Бұл нұсқа шағын бір Node.js серверге арналған; JSON-файл транзакциялық деректер қоры емес. Сервер бірнеше процесте қатар іске қосылмайды. Аватар қозғалысының уақытша координаттары сервер рестартынан кейін соңғы жауаппен бірге сақталмауы мүмкін (қайта қосылғанда сессия сақталады). Телефонда браузерлік WebGL қолдауы қажет. Пайдаланушылар үшін нақты аты-жөні қажет емес.

## Файлдар

- `server.js` — HTTP, Socket.IO, серверлік авторизация, жауаптарды сақтау, CSV.
- `public/index.html`, `style.css`, `app.js` — мұғалім және оқушы интерфейстері.
- `public/world.js` — Three.js 3D сынып, жиһаз, аватар, камера, қозғалыс.
- `test/integration.test.js` — интеграциялық тексеру сценарийі.
- `package.json` — барлық тәуелділіктер мен командалар.

Ешбір алдын ала жасалған оқушы немесе жасанды жауап статистикасы жоқ.
